# 萤火 H5 MVP 框架记录

更新时间：2026-09-21

## 当前结论

H5 MVP 的可运行框架已经搭建完成，当前可以在本地体验完整的核心流程：

> 进入演示账号 → 创建 TA → 记录记忆 → AI 模拟对话 → 查看价格 → 创建模拟订单 → 模拟支付

这一版是“先把产品跑起来”的开发底座，不代表真实渠道已经开通。所有外部服务均保留配置入口，默认使用 mock provider，避免在 API 申请期间阻塞前端和业务联调。

## 已搭建的工程

| 模块 | 位置 | 当前状态 |
|---|---|---|
| H5 用户端 | `apps/client` | uni-app + Vue 3 + TypeScript，移动优先 |
| API 服务 | `apps/server` | NestJS 风格模块化单体，默认本地演示存储 |
| 异步任务 | `apps/worker` | BullMQ 接口骨架，未连接 Redis 时只做自检 |
| 管理端 | `apps/admin` | 最小开发控制台，可查看演示概览 |
| 共享契约 | `packages/contracts` | Zod 输入校验、产品、用户、订单和消息类型 |
| 数据库规格 | `infra/migrations`、`apps/server/prisma` | Supabase/Postgres 迁移和 Prisma 映射已保留，尚未连接真实项目 |
| 本地环境 | `.env.example` | API、存储、短信、AI、图片、审核、微信支付、Stripe 均为占位 |

## H5 页面范围

当前用户端已包含 15 个页面路由：

- 首页、登录/演示入口
- 创建 TA、萤火空间
- 萤火记忆、记忆编辑、记忆详情
- AI 记忆对话
- 老照片体验页
- 价格与权益、我的订单
- 我的
- 广场、故事详情、发布故事

“故事”产品定位已保留为“广场”。公开内容默认进入待审核状态，审核服务没有接通之前不会直接公开，避免 MVP 阶段误发真实隐私内容。

## 当前可以真实验证的部分

- 页面路由、移动端布局和横向溢出检查
- 演示登录会话、HttpOnly Cookie、CSRF 和来源校验
- 用户只能读取自己创建的资料、记忆、消息和订单
- 创建 TA 前必须确认 AI 生成声明
- 记忆默认不授权给 AI，需用户明确开启
- AI 对话的回复明确标记为模拟内容，不代表本人
- 订单价格由服务端产品表决定，前端不能自行改价
- 幂等键防止重复创建订单
- 订单状态：待支付 → 已支付 → 可退款/已退款
- 广场投稿的私密/待审核隔离
- 管理端 token 缺失或过短时拒绝访问
- 生产配置或非 mock provider 会被本地演示服务拒绝启动

## 本地启动

```bash
cp .env.example .env
pnpm install
pnpm dev
```

默认地址：

- H5：`http://127.0.0.1:5173`
- API 健康检查：`http://127.0.0.1:3001/api/v1/health`
- API 能力说明：`http://127.0.0.1:3001/api/v1/capabilities`
- 管理端：单独执行 `pnpm dev:admin` 后访问 `http://127.0.0.1:5174`

如果只想单独运行：

```bash
pnpm dev:server
pnpm dev:client:h5
pnpm dev:worker
pnpm dev:admin
```

## 接入 API 时的顺序

不要同时替换所有 provider。建议按下面顺序逐项替换，并保留 mock 开关：

1. 先建 Supabase 项目，执行迁移，验证 RLS、Storage 私有桶和签名 URL。
2. 接入短信服务，完成登录、验证码频控、注销和账号删除测试。
3. 接入 AI 文本服务，先跑固定评测用例，再开放真实对话。
4. 接入对象存储和图片/音频任务，所有大文件走后台任务，不阻塞 H5 请求。
5. 接入审核服务和人工审核队列，再打开广场公开展示。
6. 申请并配置微信支付或 Stripe，先沙盒/测试环境，再打开正式商品。
7. 配置 Redis、监控、备份、告警和发布回滚流程。

## 重要边界

- 不要把 Supabase `service_role`、微信支付私钥、Stripe Secret Key 或第三方 API Key 放进 H5 环境变量。
- H5 只拿公开配置和短期访问令牌；供应商密钥只在服务端/Worker 使用。
- 不要上传真实家庭照片、声音、手机号、聊天记录或支付证书到 GitHub。
- 在短信、AI、媒体、审核和支付全部通过真实联调前，当前版本只适合内部演示和开发验收。
- 当前价格仅用于流程演示，正式价格、退款、内容授权和隐私条款仍需最终确认。

## 下一步

API 申请完成后，以 `.env.example` 为入口逐项填入环境变量，并为每个真实 provider 增加沙盒测试。接入任何一个 provider 后，都要同时补充：失败重试、超时、幂等、日志脱敏、权限测试和回滚开关。
