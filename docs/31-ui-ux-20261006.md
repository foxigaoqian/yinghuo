# 萤火 UI/UX 调整（2026-10-06）

这次调整围绕三个真实任务：第一次留下一句话、回来继续记录、找到以前保存的内容。

- 新用户在一页内选择人物并写下第一句话。昵称、头像、人物对用户的称呼可稍后补充，也允许先建立空空间。
- 返回首页和人物空间把记录、聊天放到首屏；保留最近记忆预览，缩小广场示例图片。
- 主导航「记忆」汇总所有人物的私密记忆及旧版故事；支持人物筛选，筛选后新增记录归属该人物。广场「我的分享」只列公开申请。
- 记录页首先显示归属人物与正文。标题选填，留空时取用户正文第一句或第一行；不生成额外事实。
- 草稿按账号、人物及编辑目标隔离，显示本机暂存与空间保存的差异。保存失败保留输入，成功进入详情并展示保存反馈。删除人物继续清理相关本机草稿。
- 分享从已有记忆生成独立副本，明确提示原文仍然私密，原文修改或删除不会同步副本。原表和全部旧内容保留，不做迁移或删除。
- 聊天使用「小萤·AI记忆助手」身份与形象，人物只是记忆主题。开场建议只填入输入框；发送仍需本次授权，默认不引用记忆，最多显式选择五条。输入在回复等待或网络失败期间保留。
- 「已保存」与「已设置跨设备找回」分别展示。生成找回信息后一次展示密钥并可复制空间编号和密钥。首次设置无需多一层确认，重新生成会提醒旧密钥失效。新用户不展示不能用于登录的手机号入口，旧绑定仍可管理。
- 数据加载、加载失败与真正空状态分别处理。记录、创建和聊天隐藏底部主导航；返回可用，聊天根据可视视口高度调整布局。

## 第二轮：人物主线与移动端细节

- 返回首页恢复大萤火虫的情感视觉，并把人物头像切换、添加人物、记录和对话放在同一首屏；旧「人物空间」链接兼容跳回首页，不再作为重复入口。
- 新记忆可在保存前选择「仅自己可见」或「同时分享到广场」。原记忆始终私密，公开内容是独立审核副本；公开提交失败时，私密记忆仍已保存，并提供不会重复保存原文的重试入口。
- 对话页以当前人物的名称和头像为主视觉，例如「和爷爷聊聊」；每条生成回复继续标注「AI 生成」，小萤只出现在 AI 边界说明中。
- 对话改为固定可视视口、单独滚动消息区和独立输入区，同时跟踪 `visualViewport.height` 与 `offsetTop`，避免 iOS 键盘出现时页面跳到空白区域。
- 找回方式改为可下载或在微信内长按保存的「萤火找回卡」，不要求用户记住恢复码。未验证手机号仍不作为可信找回凭据，待短信验证码链路完成后再开放。
- 全站统一 4/8px 间距节奏与 10/14/16px 圆角层级，压缩重复提示、广场首屏空隙和聊天开场提示块。

第二轮浏览器回归共 15 个移动端场景，覆盖首页人物切换、一次保存并分享、分享失败恢复、人物头像对话、找回卡下载、375px 小屏、横屏和历史对话定位。发布版本标记为 `20261006-ux2`。
