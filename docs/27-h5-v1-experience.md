# 萤火 H5 第一版体验交付

## 首次访问流程

1. 首页看到「萤火」文字标志、小萤和主要入口「为 TA 建立记忆空间」。另一入口可先读广场故事。
2. 点击主入口即建立临时体验空间；进入建档前提示仅填写虚构资料，记录约 24 小时后清除。
3. 三步填写：TA 的称呼、TA 对自己的称呼、第一段记忆。页面刷新后恢复未提交的建档草稿。
4. 保存后直接进入 TA 的私密空间；若第三步填写了故事，这段故事自动成为第一条私密记忆，默认不用于 AI。
5. 在空间选择「和 TA 的记忆说说话」：阅读 AI 标识，自行勾选希望引用的记忆并确认内容使用后发送文字。也可以继续记录文字、回看记忆，或在「广场」阅读和保存私密故事。

## 展示边界

| 入口           | 第一版实际行为                                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 建档和文字记忆 | 演示会话内可新增并回看，线上临时数据约 24 小时过期                                                                        |
| 广场           | 精选为明确标记的虚构示例；自己的投稿仅自己可见                                                                            |
| 记忆对话       | 配置模型时，可在明确同意后与萤火 AI 交谈；用户自行选择最多 5 段记忆参与当次对话，未选记忆不发送；模型不可用时不展示假回复 |
| 照片           | 仅在设备上预览，不上传或生成修复结果                                                                                      |
| 套餐           | 展示未来 ¥99／年计划价和拟议权益，不收款、不开放购买                                                                      |
| 登录           | 临时演示会话；正式账号及跨设备找回尚未提供                                                                                |

页面沿用暖色轻纹理、小萤 IP 和移动端优先布局。以上仅为可评审的 H5 V1 限时体验，不应作为真实家庭资料、长期存储或付费服务对外开放。

## 交付验收

- 从首页到建档、第一条记忆、第二条记忆、广场私密故事的操作闭环可走通。
- 建档草稿在同一浏览器刷新后仍在；清除会话或过期后无法找回。
- 广场私密故事不会进入精选；用户看到的示例标记为虚构。
- 页面无「开发演示」「正在处理」等开发提示；首次打开不闪现空态或被禁用的创建按钮。
- 模型正常时返回动态生成的文字，不冒充本人；模型失败时不存储假回复。价格页不能发起真实购买。
- 在 375px 手机与横屏检查无横向溢出；检查 Cloudflare API 与页面联动。

后续接入真实服务前，按 [Supabase H5 集成](25-supabase-h5-integration.md) 与工程运行手册完成持久化账号、权限和删除、模型审核与费用控制、媒体处理、支付回调、隐私与合规文本的独立验收。
