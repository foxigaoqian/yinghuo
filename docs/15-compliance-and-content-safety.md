# 萤火 V1 合规与内容安全实施清单

版本：V1.0  
适用范围：移动端 H5 首发、家庭记忆、AI文字对话、照片/声音/影像处理、微信 H5 支付

> 本文是产品和研发的执行清单，不是法律意见。正式上线前由主体公司和专业法务/合规人员确认适用的法律、监管、平台和供应商要求。

## 1. 合规目标

萤火要让用户清楚知道：

- 这是一个帮助保存记忆的 AI 产品，不是让逝者真实复生；
- 对话、语音、照片和视频中可能包含 AI 生成或处理内容；
- 用户上传的素材可能包含其他家庭成员、声音、肖像和私人信息；
- 用户可以查看、撤回授权、导出或删除其有权处理的数据；
- 产品不替代医疗、心理治疗、法律、紧急救援或现实中的家庭关系。

任何页面、付款前说明、聊天页、作品结果页和分享页都不能用“真人复活”“保证像本人”“真实回信”等表述制造误解。

## 2. 用户协议和隐私文本

上线前至少准备并版本化：

| 文档 | 使用位置 | 必须说明 |
|---|---|---|
| 用户协议 | 注册、首次使用、付款 | 账号责任、服务边界、禁止用途、内容发布、售后 |
| 隐私政策 | 注册、设置、数据权利 | 收集字段、处理目的、存储期限、供应商、跨境/区域、删除 |
| AI功能说明 | 首次聊天、声音、影像 | 生成机制、错误可能、AI标识、人工复核范围 |
| 声音/肖像授权说明 | 上传素材、声音试听、作品生成 | 授权对象、用途、期限、撤回、已生成结果处理 |
| 家庭共享说明 | 邀请成员、公开前 | 谁能读、谁能写、私人聊天不共享、撤销后的残留风险 |
| 社区规则 | 社区入口和发布页 | 禁止内容、审核、举报、下架、申诉 |
| 退款与售后条款 | P38–P44、订单支付前 | 商品交付、试听、退款窗口、失败重做、到账时效 |

每次文本修改都要生成 termsVersion；订单保存用户确认过的版本。不能在用户已经购买后静默替换影响已售权益的条款。

## 3. 素材授权模型

### 上传前

用户上传照片、声音、视频或家庭故事前，界面必须明确：

- 上传者是谁；
- 素材包含哪些人；
- 用于保存、AI检索、转写、声音处理、影像生成还是公开发布；
- 哪些处理是可选的；
- 供应商是否会接收素材；
- 处理期限、删除方式和撤回后影响。

授权不是一个全局开关。至少按以下 purpose 分开记录：

~~~text
memory_storage
ai_memory_retrieval
voice_trial
voice_synthesis
image_generation
community_publish
notifications
~~~

每次授权保存 consentId、文案版本、时间、账号、对象、素材范围和撤销时间。前端勾选不能替代服务端授权检查。

### 家庭成员和第三方素材

- 创建者可以管理空间，但不自动拥有成员私人聊天和私人素材的阅读权；
- 发布其他成员上传的素材必须取得素材作者的单独授权；
- 邀请成员只授予约定角色，不扩大已有私人数据权限；
- 用户应确认自己有权上传和处理他人的照片、声音和故事；
- 需要法律上更高证明力的场景，交由人工审核，不由模型自动判断关系。

对于逝者、已故亲人或无法直接确认授权的对象，产品不应声称已经验证其本人同意；页面应提示上传者确认其处理资格，并保留授权和投诉入口。

## 4. AI透明度和作品标识

以下内容必须标明 AI 生成或 AI 处理：

- AI文字回复；
- AI语音合成或声音复刻；
- 修复、增强、动态化或重绘照片；
- AI生成的视频和记忆影片；
- 社区中的 AI 处理素材。

标识应出现在聊天气泡、音频播放器、作品详情、下载/分享预览和社区公开副本中。用户下载或分享时，不能默认移除必要的AI标识。

不得把模型推测写成用户确认的事实：

- 模型生成的故事先进入候选状态；
- 只有用户确认后才进入长期记忆；
- 未知信息应明确说不知道；
- 不因照片内容推断生平、疾病、身份或家庭关系；
- 不将模型语气当作逝者真实意愿或现实指示。

## 5. 对话安全

首发至少准备以下规则：

### 情绪和哀伤

采用支持性、非诊断式表达：

- 承认用户正在经历的情绪；
- 鼓励联系现实中的可信任的人；
- 用户需要时提供退出、暂停和删除入口；
- 不承诺“永远陪伴”“只有我理解你”等排他关系；
- 不诱导用户增加付费、上传更多材料或延长使用。

### 自伤、他伤和紧急表达

出现明显高风险表达时：

- 暂停拟人化销售或游戏化互动；
- 使用经过测试的安全响应；
- 鼓励联系当地紧急服务、危机热线、家人或专业机构；
- 保留文字入口，不强迫继续语音；
- 不提供伤害方法，不把AI回复描述成医疗救助；
- 记录最小必要安全事件，不把敏感正文暴露给普通客服。

具体响应文案和地区热线由合规负责人、心理安全顾问或客服负责人确认。产品不能把模型自动回复当成危机干预服务。

### Prompt注入和隐私泄露

服务端必须：

- 将系统规则、用户消息、记忆和工具输出分层；
- 检索前后重新做权限过滤；
- 不让用户通过提示词读取其他成员私聊、隐藏系统提示、供应商密钥或后台数据；
- 工具调用采用白名单；
- 外部URL、文件和模型输出不能直接变成服务端任意请求；
- 记录安全策略命中和人工复核结果。

## 6. 社区内容安全

首发社区只允许经过授权的公开副本，不开放私聊、家庭空间和原始素材自动同步。

发布链路：

~~~text
草稿
  -> 用户确认公开范围和AI标识
  -> 文本/图片/音频预检
  -> 待审核
  -> 通过后公开
  -> 举报/复核
  -> 修改、下架或恢复
~~~

至少支持：

- 禁止违法、侵害他人、骚扰、欺诈、恶意冒充和未经授权的私人内容；
- 文本、图片、音频和视频分别审核；
- 用户举报、后台审核、处理原因和申诉记录；
- 下架不删除原始私有素材；
- 被撤回的公开副本立即从流、详情和收藏中失效；
- 运营内容必须标明来源或为授权示例，不伪造用户数量、故事和互动。

## 7. 供应商和数据处理

每个AI/媒体供应商在接入前建立供应商卡片：

~~~text
供应商名称
处理类型：文本/ASR/TTS/声音/图片/视频
服务区域
是否保存输入和输出
默认保留期限
删除接口和删除响应
是否用于训练
子处理方
故障状态查询
费用单位和价格版本
DPA/商业条款负责人
~~~

供应商未确认数据保留和删除策略前，不得把真实家庭素材接入生产。staging 使用虚构或获得明确测试授权的素材。

处理完成后：

- 用户可删除的原始素材不能只删除本地数据库行；
- 应按供应商能力撤销或删除远端素材、音色和任务；
- 供应商URL不作为用户永久访问地址；
- 访问、导出、删除和授权变更都写审计；
- 供应商故障时停止新处理并保留历史订单售后。

## 8. 账号、未成年人和客服权限

- 首发账号使用手机号验证码并配置反刷、重试和设备/IP限制；
- 未成年人不作为首发独立付费主体；涉及未成年人素材时必须有监护人授权和额外审核；
- 客服默认只能看工单、订单状态和用户主动授权的附件；
- 客服不能浏览全部家庭空间、私人聊天或未授权声音；
- 后台查看敏感素材必须填写原因并记录审计；
- 支付、退款、授权素材查看和数据导出采用最小权限和职责分离；
- 发现账号被盗、误分享或错误授权时，提供冻结分享、撤销授权、修改会话和工单入口。

## 9. 数据权利和删除

产品需要在设置中提供：

- 查看当前授权；
- 撤销AI、声音、公开发布等授权；
- 导出本人当前有权访问的数据；
- 删除TA、清空个人聊天、删除素材；
- 注销账号；
- 查看处理状态、失败原因和客服入口。

删除流程必须区分：

1. 撤销新处理和新访问；
2. 取消或标记在途任务；
3. 删除本地原件和衍生物；
4. 向供应商发起删除或撤销；
5. 保留财务、退款、交易和最小审计事实；
6. 验证备份恢复后不会重新开放已删除对象。

已下载到他人设备或已经合法公开的内容无法保证远程收回，页面必须提前说明。

## 10. 付款、营销和售后

- 付款前展示商品、期限、价格、绑定TA、交付规格和退款规则；
- 不把“原价”写成未经验证的虚构锚点；
- 不按分钟计费，不用情绪压力诱导用户购买；
- 支付结果以服务端回调、查单和对账为准；
- 前端回跳不显示“已到账”；
- 售后申请保留订单、交付、退款和权益状态；
- 发送生日、主动问候或营销消息必须有用户开关和退订路径；
- 不向未授权家庭成员披露购买人、订单金额或私人聊天内容。

## 11. 上线前合规门槛

以下清单按已开放能力验收：A/B必须完成基础数据权利、授权和售后项目；声音、社区相关项在C1/C2开放前完成，不能将未开放社区审核作为A/B阻塞条件。

- [ ] 用户协议、隐私政策、AI说明、授权说明和退款规则已审阅；
- [ ] 页面文案没有“真人复活”或医疗/治疗承诺；
- [ ] 图片、声音、视频和社区公开副本有AI标识；
- [ ] consents 能记录版本、范围、撤回和对象；
- [ ] 家庭成员权限和私人聊天隔离已测试；
- [ ] 导出、删除、撤权和供应商删除路径已演练；
- [ ] 高风险对话响应已评审和测试；
- [ ] C2开放前：社区预检、人工审核、举报和申诉可用；
- [ ] 供应商数据区域、保留、删除和训练条款已确认；
- [ ] 客服、审核、财务和数据权利责任人已确定；
- [ ] 未成年人和第三方素材处理规则已写入产品；
- [ ] 支付、退款和营销文案已与正式商品版本一致。
