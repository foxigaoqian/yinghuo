# 前端架构与52个页面开发规格

## 1. 页面组织

用户端建议uni-app + Vue 3 + TypeScript，V1 只构建移动端 H5；基础组件用Wot UI评估版，业务组件自己实现。四Tab为首页、萤火、社区、我的。下列路由是逻辑路径，URL参数不构成授权。组件、接口和状态机保持平台无关，V2 再增加微信小程序构建与真机适配。

P编号沿用产品V2。表中阶段是首次完整开放阶段，A/B阶段允许有只读简版；未完成能力由bootstrap统一返回，不只是前端隐藏。52页覆盖目标产品，不全部塞进首发。

## 2. 通用UI与交互

- 390×844为逻辑设计基准，同时验证320–430宽、系统字号、键盘、安全区域。底色#F5F2EC、卡片#FAF8F3、导航#F0ECE5、文字#443A30、点缀#F5C542。
- 细微低对比磨砂纹理，避免大面积深米黄和复古旧纸；重模糊不作为核心层级。正文约16px、辅助14px、触控区至少44px、按钮约48px。
- 不强制陌生关系头像。无照片用名字占位；一页创建；聊天使用自然气泡和直接图片，不展示检索卡。
- 页面统一loading/empty/error/ready，无数据不伪造示例记录。按钮submit期间禁用，但后端仍做幂等。
- Pinia只保存会话概况、当前TA、个人偏好、上传草稿与任务ID，不长期明文缓存完整私聊和录音。登出、撤权、切账号必须清理隔离缓存。
- 共享组件：PageShell、TaIdentity、MemoryItem、ChatBubble、VoicePlayer、UploadCard、AsyncTaskStatus、PlanCard、PriceBreakdown、PermissionNotice、EmptyState、ErrorState。
- 草稿按当前用户与业务ID分区；登录前仅本地临时草稿，上传正式私有素材前登录，避免匿名存储滥用。登录中断不主动清空草稿，但浏览器重启/系统清理导致文件失效时应诚实要求重选。
- 公共导航进入TA相关页面先选目标TA；回退保留列表位置。图片/音频完整资源按需加载，不在列表一次取全部原件。

## 3. 首期 H5 与 V2 迁移边界

V1 只验收移动端 H5，不把小程序编译、审核和真机行为作为当前交付条件。

| 能力 | V1 H5 | V2 小程序 |
|---|---|---|
| 登录 | 手机号验证码、HttpOnly会话、白名单returnTo | 小程序code登录与账号绑定 |
| 支付 | 微信 H5 下单，返回 h5Url，跳转后回到支付结果页 | JSAPI 下单与 wx.requestPayment |
| 聊天更新 | SSE可选，JSON轮询为恢复基线 | 先复用JSON轮询，再评估分块或WebSocket |
| 录音/上传 | 浏览器安全上下文、格式和权限提示 | 原生录音、选择器与保存相册 |
| 分享 | H5链接，公开内容与邀请token | 小程序分享卡片 |
| 推送 | 站内通知和可选短信/邮件；不承诺H5后台推送 | 经用户授权后接入订阅消息 |

H5 支付页面必须同时验证普通手机浏览器和微信内置浏览器。两者都先走 wechat_h5；如果真实商户联调证明微信内场景需要 JSAPI，作为 V2 增量，不在 V1 临时混入第二套支付流程。

支付结果页不能根据浏览器跳转直接显示“已支付”，必须读取 GET /orders/{id}，必要时调用一次受频控的 POST /orders/{id}/reconcile。

## 5. 逐页实施要求

接口均相对`/api/v1`，完整权限和DTO见[API契约](05-api-contracts.md)。记录中的早期说法若与开发细化冲突，以本节“实现重点”和[决策记录](10-decisions.md)标出的补充规则为准。

### P01 首页

- **入口/阶段**：首页Tab或分享链接；A。
- **内容**：品牌主张、创建入口、场景照片／照片动态／声音入口、示例故事；游客、已登录未创建、已创建三种布局。
- **操作**：游客可看内容；创建时登录；老用户主按钮改为继续与某位TA聊天，任务卡回到对应任务。
- **状态与权限**：加载失败保留导航；无TA显示创建引导。推荐区不公开私人内容，声音未上线时隐藏收费入口。
- **读取接口**：`GET /home`；`GET /bootstrap`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：游客、未建档、已建档三种状态；继续最近任务的目标ID来自服务端。

### P02 登录

- **入口/阶段**：创建、支付、收藏、发布或受邀加入时触发；A。
- **内容**：手机号、验证码登录入口、协议勾选和返回按钮；保留来源页面及未提交草稿。
- **操作**：提交手机号到03；登录成功回原操作。后续小程序可增加平台登录并绑定同一账号。
- **状态与权限**：手机号错误就地提示；协议不默认勾选；取消返回可浏览页面，不能丢上传素材。
- **读取接口**：`GET /legal/{type}`。
- **提交接口**：`POST /auth/otp`。
- **实现重点**：校验手机号与主动协议勾选；returnTo限定内部路由。

### P03 验证码

- **入口/阶段**：02提交手机号后；A。
- **内容**：脱敏手机号、验证码输入、重发倒计时、修改手机号；避免重复注册造成多个账号。
- **操作**：校验成功恢复原创建／订单／邀请；手机号变更返回02。
- **状态与权限**：错误、过期、发送失败分别提示；重发频率由服务端控制，不能用前端倒计时作为唯一校验。
- **读取接口**：不额外读取。
- **提交接口**：`POST /auth/otp/verify`。
- **实现重点**：challengeId和脱敏手机号；倒计时不代替服务端限流。

### P04 协议阅读

- **入口/阶段**：登录页、结算页和账号设置；A。
- **内容**：按文档类型复用模板：用户协议、隐私说明、声音授权、购买与售后规则；展示版本和更新时间。
- **操作**：阅读后回来源页；同意行为在来源页完成。声音材料用途说明与营销订阅分开。
- **状态与权限**：内容无法加载时允许稍后重试；不得把打开文档记成用户同意；具体上线文本另行定稿。
- **读取接口**：`GET /legal/{type}`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：type和version；打开协议不自动记录同意。

### P05 消息中心

- **入口/阶段**：首页消息图标或我的；B。
- **内容**：生成结果、支付与售后状态、邀请、用户主动订阅的问候；按事项分组，展示未读。
- **操作**：点击直达任务、订单、邀请或相关TA；可关闭问候提醒。
- **状态与权限**：没有消息时显示空态；已删除对象显示已失效；推送是否可达取决于实际渠道授权。
- **读取接口**：`GET /notifications`。
- **提交接口**：`POST /notifications/read`。
- **实现重点**：离开任务页后能从消息回原任务；A可先以作品/导出详情恢复。

### P06 我的萤火

- **入口/阶段**：萤火Tab；A。
- **内容**：人物空间列表、最近活动、日常记录／纪念空间标签和新建入口；头像仅用真实上传照片或名字占位。
- **操作**：选择人物到08；新建到07。第二位TA先保存草稿，在开通前写明需要独立套餐。
- **状态与权限**：免费名额占用时不在提交后突然收费；已付费空间到期仍可见，原有基础内容可访问。
- **读取接口**：`GET /profiles`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：active/draft/已到期均可区分，不能隐藏已保存人物。

### P07 快捷创建TA

- **入口/阶段**：01或06；A。
- **内容**：一页完成：TA称呼必填；关系、姓名、照片、TA对你的称呼和一句记忆均可跳过。关系用文字选项。
- **操作**：点击创建，成功提示后进入19；后续从09补资料。首句避免凭空编造过去经历。
- **状态与权限**：不强迫上传头像、生日或逝世日期。离开存草稿；重复点击不重复建空间；创建失败可重试。
- **读取接口**：`GET /bootstrap`。
- **提交接口**：`POST /profiles`。
- **实现重点**：displayName必填；免费资格用完先显示需套餐，提交后保留draft。

### P08 TA的萤火空间

- **入口/阶段**：06人物卡或聊天顶部；A。
- **内容**：名称、简短介绍、和TA说说话、照片／声音／故事统计、记忆时间线、共同记录与权益入口。
- **操作**：聊天到19；查看记忆到13；添加到14；共同记录到10。默认不展示生卒年。
- **状态与权限**：记忆主人与实际账号分开；没有照片也能正常显示。游客无法直接打开私有空间。
- **读取接口**：`GET /profiles/{id}`；`GET /profiles/{id}/entitlements`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：profileId；摘要按当前账号可见范围统计。

### P09 人物资料

- **入口/阶段**：08编辑或20设置；A。
- **内容**：姓名、称呼、关系、性格描述、常说的话、日常记录／纪念空间；照片和日期可选。
- **操作**：保存后更新空间与后续对话资料；历史聊天不重写。删除人物使用独立确认与导出提示。
- **状态与权限**：创建者可编辑；协作者权限按12执行。修改纪念类型不自动发布或触发问候。
- **读取接口**：`GET /profiles/{id}`。
- **提交接口**：`PATCH /profiles/{id}`。
- **实现重点**：expectedVersion；称呼与共享人物资料分开。

### P10 共同记录成员

- **入口/阶段**：08共同记录入口；B。
- **内容**：单独标明记忆主人；下方只列真实受邀账号、角色、邀请状态、最多5人含创建者。
- **操作**：创建者邀请到11并设置12；成员可退出；移除后即时停止新增访问。
- **状态与权限**：记忆会员或声音会员可邀请；体验中未具备该功能时不可售卖此权益。私聊和订单不默认共享。
- **读取接口**：`GET /profiles/{id}/members`。
- **提交接口**：`POST /profiles/{id}/invitations`；`DELETE /profiles/{id}/members/{userId}`。
- **实现重点**：剩余名额含owner，成员不展示私聊与私人订单。

### P11 邀请详情

- **入口/阶段**：邀请链接、二维码或消息中心；B。
- **内容**：邀请者、TA名称、将获得的记忆访问权限、有效状态和接受／拒绝按钮。
- **操作**：未登录先到02，返回后确认加入；接受后到08。过期可联系邀请者重新发起。
- **状态与权限**：链接不直接泄露素材；建议单次使用、7天有效，可撤销。人数已满和账号已加入单独提示。
- **读取接口**：`GET /invitations/{token}`。
- **提交接口**：`POST /invitations/{token}/accept`；`DELETE /invitations/{id}`。
- **实现重点**：登录前只有最小邀请预览；接受并发不得超5人。

### P12 权限管理

- **入口/阶段**：10成员菜单；B。
- **内容**：创建者、共同记录者、仅查看三种角色；分别说明上传、编辑、邀请和导出权限。
- **操作**：保存后立即生效；修改他人角色前显示影响。创建者不可把自己误移除。
- **状态与权限**：协作者默认只改自己的记录；跨作者编辑须授权。移除成员不自动删除其已提交的家庭记录。
- **读取接口**：`GET /profiles/{id}/members`。
- **提交接口**：`PATCH /profiles/{id}/members/{userId}`。
- **实现重点**：role和expectedVersion；不可把自己改成最后一个非owner。

### P13 记忆库

- **入口/阶段**：08照片／故事／声音入口；A。
- **内容**：全部、照片、故事、声音、视频筛选；时间顺序、搜索、数量和添加入口；原始与AI生成标签分开。
- **操作**：点记录到15；照片预览到16；录音到17；添加到14。
- **状态与权限**：容量满时显示清理、导出和扩容；不阻止读取旧内容。无结果与无任何记录使用不同空态。
- **读取接口**：`GET /profiles/{id}/memories`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：type/query/cursor；列表返回position，回退不重置滚动。

### P14 添加或编辑记忆

- **入口/阶段**：08、13、聊天消息菜单、作品结果；A。
- **内容**：类型选择、文件或正文、标题、日期可选、人物关联、是否允许用于AI对话的说明。
- **操作**：保存到该TA私有或家庭范围；需公开时另开35发布草稿。聊天提炼的记忆经用户确认再保存。
- **状态与权限**：支持草稿、上传进度与失败重试；重复保存不生成副本。录音／视频转写与AI识别可能有误，可编辑。
- **读取接口**：`GET /memories/{id}`。
- **提交接口**：`POST /uploads`；`POST /profiles/{id}/memories`；`PATCH /memories/{id}`。
- **实现重点**：body/assetIds/visibility/useForAi；上传与保存分状态。

### P15 记忆详情

- **入口/阶段**：13记录卡或消息引用；A。
- **内容**：完整正文、素材、来源标签、时间、作者和可用操作；AI生成图片／音频有持续标识。
- **操作**：编辑到14；创建者或有权限者可删除；分享至社区进入35并再次确认公开范围。
- **状态与权限**：协作者不见他人私聊；删除确认说明对记忆检索的影响，历史聊天里的文本不随之伪造改写。
- **读取接口**：`GET /memories/{id}`。
- **提交接口**：`DELETE /memories/{id}`。
- **实现重点**：公开发布为新草稿；记忆删除先停检索。

### P16 照片查看器

- **入口/阶段**：13、15或聊天图片；A。
- **内容**：大图、前后切换、缩放、说明；允许时可保存原图；生成图保留AI标签。
- **操作**：返回原相册位置；创建作品到对应工具；保存或下载只针对当前有访问权的图片。
- **状态与权限**：加载原图失败先显示缩略图与重试；无权限不给原图链接；处理结果不覆盖上传原件。

- **状态与权限**：不显示他人订单；无订单提示先体验；列表不可把处理中的作品当成支付失败。
- **读取接口**：`GET /orders`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：仅本人；状态筛选与cursor；不混入家人账单。

### P43 订单详情

- **入口/阶段**：42、任务或支付结果；B。
- **内容补充**：微信渠道交易状态、服务端订单状态和退款状态分开显示。
- **内容**：订单编号、实付与抵扣、支付状态、服务期限、任务状态、售后记录、客服入口。
- **操作**：查看作品／权益，申请44退款，复制编号或下载可提供的凭证。
- **状态与权限**：重复扣款先核对交易；退款与任务结果分别留痕；付费权益变更有可追溯记录。
- **读取接口**：`GET /orders/{id}`。
- **提交接口**：`POST /orders/{id}/cancel`。
- **实现重点**：支付/交付/退款分别显示，任务与售后入口始终可达。

### P44 退款与售后申请

- **入口/阶段**：43或任务失败入口；B。
- **内容**：退款原因、关联作品、可选补充描述、已承诺处理时间；进度与处理结果。
- **操作**：提交后回订单；修复、退款、关闭工单各有说明；原路退款失败可继续联系支持。
- **状态与权限**：失败服务不强制换积分；升级抵扣要恢复旧权益；任何驳回均说明具体原因和后续入口。
- **读取接口**：`GET /refunds/{id}`。
- **提交接口**：`POST /orders/{id}/refunds`。
- **实现重点**：原因/可选附件/处理承诺；失败保留原申请而非重复退款。

### P45 服务与容量

- **入口/阶段**：我的、容量提示或会员入口；B。
- **内容**：每位TA的套餐、有效期、素材已用／总容量、留声作品剩余份数、扩容记录。
- **操作**：续费、升级、扩容、管理素材；独立作品剩余份数链接26。
- **状态与权限**：取消文字次数和语音分钟余额。到期超额暂停新增，旧内容仍可读和导出。
- **读取接口**：`GET /me/services`；`GET /profiles/{id}/entitlements`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：容量和期限，无聊天次数或分钟余额；扩容D才开放。

### P46 我的

- **入口/阶段**：我的Tab；A。
- **内容**：账号、我的作品、订单、服务与容量、收藏、问候、隐私设置、帮助；私有记录与公开主页分开。
- **操作**：进入相应页面；游客显示登录但可打开帮助与价格。
- **状态与权限**：只展示实际有权限的TA与数据；未开通服务不给虚构余额。
- **读取接口**：`GET /me`；`GET /me/services`。
- **提交接口**：导航或当前模板内操作。
- **实现重点**：各模块按能力开关展示；作品/订单在B后可达。

### P47 账号设置

- **入口/阶段**：46；A。
- **内容**：昵称、头像、手机号绑定、登录设备、退出登录；字体大小偏好可作为本页子视图。
- **操作**：修改资料；敏感账号操作需再次校验；退出前提示未保存草稿。
- **状态与权限**：更换手机号需验证新旧账号归属，不能仅凭前端修改；账号注销在48明确影响后办理。
- **读取接口**：`GET /me`；`GET /me/sessions`。
- **提交接口**：`PATCH /me`；`DELETE /me/sessions/{id}`；`POST /auth/logout`。
- **实现重点**：手机号更换走独立验证；退出清理本人私有缓存。

### P48 隐私与数据

- **入口/阶段**：46／47；A。
- **内容**：私有与家庭共享范围、授权记录、数据导出、删除人物、撤销素材授权、账号注销。
- **操作**：导出申请到49；删除／注销需确认具体对象和影响，先给导出选择。
- **状态与权限**：用户授权撤销后停止相关新生成；共享记录与私人记录逐项处理，不能误删其他成员个人数据。
- **读取接口**：`GET /me/consents`。
- **提交接口**：`POST /consents/{id}/revoke`；`POST /exports`；`POST /me/deletion-requests`；`POST /profiles/{id}/deletion-requests`。
- **实现重点**：展示范围和影响；授权撤回先阻止新处理。

### P49 导出记录

- **入口/阶段**：48或21；A。
- **内容**：导出范围、申请时间、处理中／可下载／已过期；建议包含素材与可读正文、元数据。
- **操作**：申请与下载；链接过期可重生成；返回原空间或隐私页。
- **状态与权限**：校验当前账号和素材权限；下载链接设有效期，不通过公开社区链接分发私有导出文件。
- **读取接口**：`GET /exports`；`GET /exports/{id}`。
- **提交接口**：`POST /exports`。
- **实现重点**：处理/失败/可下载/过期；下载前重验权限。

### P50 问候与提醒设置

- **入口/阶段**：46、纪念日页或消息设置；D。
- **内容**：默认关闭；选择TA、日期类型、消息方式、接收时间和免打扰；区分服务消息与陪伴问候。
- **操作**：明确开启后才排任务；可暂停或删除；试发样例不替用户默认授权推送。
- **状态与权限**：受渠道授权和套餐权益影响；到期停止新高级问候。用户关闭后，已排未发任务也取消。
- **读取接口**：`GET /reminders`。
- **提交接口**：`POST /reminders`；`PATCH /reminders/{id}`；`DELETE /reminders/{id}`。
- **实现重点**：默认关闭；时区/免打扰/渠道订阅；关闭撤销已排队任务。

### P51 纪念日管理

- **入口/阶段**：50或08；D。
- **内容**：生日、团聚日、自定义纪念日；公历／农历标记、年份可选、是否提醒。
- **操作**：保存日期；需要自动问候时到50选模板与时段。
- **状态与权限**：不自动推断逝世日；农历和闰月转换未完成前不提供不可靠提醒，显示下一次实际日期供确认。
- **读取接口**：`GET /profiles/{id}/anniversaries`。
- **提交接口**：`POST /profiles/{id}/anniversaries`；`PATCH /anniversaries/{id}`；`DELETE /anniversaries/{id}`。
- **实现重点**：历法/闰月/年份可选；预览下次实际日期确认。

### P52 帮助与反馈

- **入口/阶段**：46、订单、上传失败或试听页；A。
- **内容**：功能说明、素材示例、收费问答、隐私说明、工单提交和处理进度。
- **操作**：按问题带入最少必要的订单／任务编号；用户确认后再附素材，接收处理结果。
- **状态与权限**：人工服务时段和预计响应应与团队能力一致；不宣称全天真人在线或医疗心理治疗。
- **读取接口**：`GET /help`；`GET /support-tickets`；`GET /support-tickets/{id}`。
- **提交接口**：`POST /support-tickets`；`POST /support-tickets/{id}/replies`。
- **实现重点**：类型/正文/自愿附材料；订单/任务可带入，不默认发送私聊。

## 6. 前端验收

每条主要任务至少覆盖：游客到登录恢复、回退、刷新、断网、重复点击、过期、接口权限拒绝、大字体、键盘遮挡和生成中离开再进入。前端不伪造支付结果或供应商进度。

V1 至少检查微信内置浏览器与普通手机浏览器的登录、上传、H5支付跳转、支付取消、支付返回和订单恢复。不把支付页面跳转当作到账凭证；小程序 iOS/Android 真机、原生录音、JSAPI 支付和订阅消息属于 V2 验收。

P30原件永久保留规则优先于旧方案里的“保留原图开关”；P26开发稿建议统一“200字”的Unicode计数；P15公开其他作者的家庭素材需另有授权。P07免费资格用完时先提示并保存draft，不能提交后突然收费。
