# 全站交互总原则

不是做“数字人后台”，而是做一个用户几乎不用学习的家庭记忆空间。

| 原则 | 落地要求 |
| --- | --- |
| 1. 先使用，后注册 | 首次访问自动生成匿名身份；不把手机号、密码、注册放在核心体验之前。 |
| 2. 一屏一个任务 | 创建、聊天、上传、保存、邀请等页面，每屏只强调一个主动作。 |
| 3. 系统能知道的，不再问用户 | 来源、设备、时间、用户 ID、当前人物、今日状态等尽量自动识别。 |
| 4. 资料渐进补全 | 不做大表单。名字、关系、称呼足够开始；照片、声音、故事以后慢慢补。 |
| 5. 任何动作都留下痕迹 | 保存后要在人物、记忆、时间线、家庭空间中看得见，避免“点完什么都没变”。 |
| 6. 先证明价值，再收费 | 声音、照片动态化、深度能力优先提供预览，再决定是否购买。 |
| 7. 空状态必须给下一步 | 不是“暂无数据”，而是解释 + 主按钮，继续推动用户完成第一次行为。 |
| 8. 对逝者身份保持真实边界 | 不让 AI 自称本人；未知事实不编造；AI 推断不可自动写入真实记忆。 |

> 核心判断 这个产品最重要的 UX 不是视觉，而是“状态连续性”：用户今天留下的内容，明天、换页面、刷新、换设备后都还能正确回来。

# 全站信息架构

移动端优先，减少一级入口，核心任务永远 1–2 次点击可达。

## 产品结构

首页  
- 新用户：留下一个重要的人  
- 回访：继续和 TA 聊聊  

创建 TA（3 步轻创建） → 聊天页 → 记忆 / 照片 / 声音 / 重要日子 → 家庭共建 → 我的家庭空间

## 建议底部导航

| 一级入口 | 职责 |
| --- | --- |
| 首页 | 新用户进入创建；回访用户恢复最近人物和最近动作。 |
| 聊天 | 直接回到最近聊天；有多个 TA 时先展示人物选择。 |
| 记忆 | 故事、照片、声音、重要日子统一入口。 |
| 我的 | 家庭空间、数据保护、邀请家人、订单、帮助与设置。 |

> 不要放到一级导航 支付、声音生成、主动消息设置、账号找回、隐私、删除、反馈等均为低频动作，从具体场景或“我的”进入。

# 用户状态机

页面不是固定的；同一页面要根据用户是谁、做过什么、当前环境是什么而改变。

首次访问 → 自动创建匿名账户 → 创建第一个 TA → 第一次聊天 → 产生第一段已确认记忆 → 回访用户

并行状态：
- 有资产未绑定 → 提示“保护这些记忆”
- 已绑定 → 跨设备可恢复
- 家人邀请 → 共同补充
- 付费能力 → 预览后购买
- 微信内打开 → 右上角引导 → 外部浏览器 → 可添加桌面

| 状态 | 页面应如何变化 |
| --- | --- |
| 匿名新用户 | 不展示注册门槛；自动拥有 user_id；直接创建 TA。 |
| 有内容未绑定 | 在“我的”或关键保存节点温和提示绑定手机号。 |
| 回访用户 | 首页优先恢复最近 TA、最近聊天和未完成内容。 |
| 家庭受邀者 | 先看到“谁邀请你记录谁”，允许先贡献一条内容再注册。 |
| 付费用户 | 购买后的能力、订单、生成结果必须永久绑定到账户。 |
| 换设备用户 | 手机号/家庭编号找回；若新设备已有临时数据，支持合并。 |

# 首页：新用户态 / 回访态

首页最重要的不是介绍功能，而是让用户马上进入下一步。

## A. 新用户首页

- Logo / 帮助
- 主标题：把你记得的 TA，慢慢留下来
- 副标题：不需要准备完整资料，从一个名字、一段故事开始就好。
- 主按钮：留下一个重要的人
- 次入口：了解我们如何使用 AI
- 三条价值说明：不用先整理资料 / 每段记忆由你确认 / 可以和家人一起记录

## B. 回访用户首页

- 欢迎语
- 最近 TA 卡片
- 上次聊天时间/上下文
- 主按钮：继续聊聊
- 最近留下的记忆
- 快捷动作：想起了一件事 / 看全部

> 自动逻辑 有 TA 且存在最近会话时，首页直接恢复；无 TA 才显示创建入口。不要让回访用户再次看到完整营销首页。

# 创建 TA：只做 3 步

目标：60 秒内开始第一次聊天。

| 步骤 | 页面结构与行为 |
| --- | --- |
| Step 1 · TA 是你的谁？ | 按钮直选：妈妈 / 爸爸 / 爷爷奶奶 / 外公外婆 / 爱人 / 朋友 / 其他。选择即进入下一步，不额外确认。 |
| Step 2 · 我们怎么称呼 TA？ | 一个输入框。可填真名，也可填熟悉的称呼。若上一步选“妈妈”，标题可直接变成“妈妈叫什么名字？” |
| Step 3 · TA 平时怎么叫你？ | 一个输入框 + “以后再说”。用户不知道时允许跳过。 |

> 不要出现 “创建智能体、训练角色、上传数据集、设定 Persona、知识库”等技术词。创建完成后系统直接进入聊天，不再加一页“创建成功”。

# 聊天页：产品核心页面

聊天页不是纯聊天框，而是“关系 + 记忆 + 下一步动作”的中心。

| 区域 | 规则 |
| --- | --- |
| 顶部人物条 | 头像、称呼、更多菜单；多个 TA 时支持切换。 |
| 轻说明 | 只在首次出现一次：回应来自用户保存资料与 AI 生成，不假装真人本人。 |
| 首次开场 | 4 个可点击话题卡，避免空白输入框让用户不知道说什么。 |
| 输入区 | 文字为 P0；语音输入可后续。输入自动保存草稿。 |
| 长按/更多 | 可“保存为记忆 / 纠正这段回应 / 举报不合适内容”。 |

首次话题卡：
- 我有点想 TA 了
- 想说说今天发生的事
- 想记录以前的一件事
- 我不知道说什么

> 未知事实 AI 没有依据时，不得编造共同经历。标准策略：承认没有这段记录 → 邀请用户讲述 → 对话结束后询问是否保存。

# 自动发现记忆 + 记忆中心

把维护“知识库”变成自然聊天中的轻动作。

候选记忆流程：

对话里出现可能的重要信息 → 系统识别候选记忆 → 聊天后出现轻卡片 → 用户选择“留下来 / 不用” → 只有确认后写入真实记忆

## 记忆中心结构

| 栏目 | 内容 |
| --- | --- |
| TA 是怎样的人 | 性格、习惯、喜好、口头禅；尽量由真实输入产生。 |
| 你们之间的故事 | 时间线式展示，可编辑来源与描述。 |
| TA 常说的话 | 用户确认的原话或明确记忆，不自动伪造。 |
| 重要的人和事 | 家庭成员、朋友、工作、地点等关系信息。 |
| 照片 / 声音 / 日子 | 统一关联到 TA，后续可关联到具体故事。 |

> 来源标识 每条记忆至少保留 source：用户手动输入 / 家人补充 / 聊天中确认 / 导入资料。AI 推断只能作为候选，不直接成为事实。

# 照片与声音：先保存，再增强

上传本身就是价值；AI 动态化、声音模拟是后置增值能力。

## 照片页

空状态：
- 这里还没有照片
- 放一张你最喜欢的照片进来吧。
- 主按钮：添加第一张照片

有照片后：
- 2 列照片流
- 点开 → 时间 / 人物 / 故事（选填）

## 声音页

- 主按钮：上传一段旧语音
- 原始语音列表
- AI 增强入口：试着生成一句熟悉的声音
- 明确标注：AI 模拟效果

> 付费前置条件 AI 声音/照片增强必须先提供短预览或效果说明，再出现购买；不要把“上传资料”直接等同于“付费训练”。

# 重要日子与主动消息

主动联系不是“定时群发”，而是利用已经知道的上下文，在合适的时候轻轻出现。

| 信号 | 使用方式 |
| --- | --- |
| 重要日子 | 生日、纪念日、用户自定义日期。添加时只需要名称 + 日期，可选备注。 |
| 近期事件 | 聊天里用户提到“明天面试”等，系统可以生成候选提醒，但需用户允许。 |
| 人物习惯 | 例如“以前晚上会问有没有吃饭”，来自已确认记忆。 |
| 安静时段 | 默认夜间不打扰；用户可调整。 |

选项：
- 暂时不用
- 偶尔关心我
- 像以前那样多问问我

> 体验红线 主动消息必须可关闭、可调整频率、可查看为什么会收到；不要暗示“TA 主动从另一个世界联系你”。

# 家庭共建：天然裂变，但先做成“共同记录”

一个人的记忆不完整，家庭成员可以补不同的故事、照片和声音。

邀请链路：
发起人 → 邀请家人一起记录 → 生成分享链接 → 受邀人打开 → 无需先注册 → 留下一段故事/添加照片 → 再提示绑定账号

| 角色 | 建议权限 |
| --- | --- |
| 查看者 | 只能看被允许的内容。 |
| 贡献者 | 可以提交故事/照片/声音，默认进入“待确认”或标记贡献来源。 |
| 管理者 | 创建者或授权家人，可以管理成员、删除内容、调整权限。 |

> 不要做成 “协作者后台 / 团队工作区 / 邀请成员管理 SaaS”。前台语言一直保持“家人一起记录”。

# 我的家庭空间

不是账户资料页，而是“我已经留下了什么”的状态中心。

模块：
- 人物资产概览：记忆、照片、声音、共同记录人数
- 主按钮：继续聊天
- 最近记录
- 家人一起记录
- 重要日子
- 数据保护：未绑定时显示“保护我的记录”
- 低频入口：订单、通知、隐私、帮助、删除

# 手机号绑定与账号找回

绑定发生在用户已有资产之后，而不是进入产品之前。

绑定页必须显示：
- 已保存多少记忆/照片
- 绑定后换手机可以找回
- 主按钮：保护我的记录
- 次按钮：暂时不用

## 换设备找回

| 阶段 | 规则 |
| --- | --- |
| 入口 | “我的 → 找回我的家庭空间”，或新设备首页底部的“我之前用过”。 |
| 方式 | 手机号验证码为主；家庭编号可作为辅助定位，不单独承担高风险验证。 |
| 恢复 | 恢复 TA、聊天、记忆、照片、声音、重要日子、订单、成员关系。 |
| 冲突 | 新设备已经产生临时内容时，先提示合并，不直接覆盖。 |

> 家庭编号 可生成易复制的用户/家庭编号用于客服定位，但不要把纯编号包装成足以绕过身份验证的恢复凭证。

# 付费与增值能力

首版尽量按具体价值收费，而不是一上来推“会员”。

推荐链路：
上传旧语音 → 生成短试听 → 用户听到效果 → 生成完整版 · ¥XX → 支付成功 → 任务执行 → 结果进账户

| 状态 | 体验要求 |
| --- | --- |
| 支付成功 | 结果与订单都绑定账户；返回原场景，不把用户丢到孤立“成功页”。 |
| 支付失败 | 明确“未完成”，保留所有输入，提供“重新支付 / 稍后再说”。 |
| 生成失败 | 支付与生成状态分离；付费后失败应支持自动重试/补偿，不要求再次付款。 |
| 刷新/关闭 | 任务后台继续；回到“我的 → 订单/生成记录”可查看状态。 |

> 首版建议收费点 声音模拟、照片动态化、高清生成、长内容生成等可验证付费；基础文字记录与基础聊天尽量降低首次付费门槛。

# 微信内打开、浏览器与桌面入口

根据当前环境自动给正确提示，不让普通用户自己排查兼容问题。

| 环境 | 页面行为 |
| --- | --- |
| 微信 | 首次显示右上角定位引导；可关闭；同设备不要每次重复弹。 |
| iPhone Safari | 适当时机引导“分享 → 添加到主屏幕”，不要首屏立即弹。 |
| Android Chrome | 支持添加到主屏幕/PWA 时再显示安装提示。 |
| 已从桌面打开 | 不再显示安装教育；直接恢复最近 TA。 |

> 触发时机 “添加桌面”应在用户完成至少一次核心行为后再出现，比首次打开立即要求安装更自然。

# 空状态、加载、网络与草稿恢复

真正成熟的 UX 要先设计“没有数据”和“出错”时长什么样。

| 场景 | 标准处理 |
| --- | --- |
| 没有记忆 | “还没有留下故事” + “想起了一件事”按钮。 |
| 没有照片 | “放一张你最喜欢的照片进来吧” + 添加照片。 |
| 没有声音 | 解释旧语音即可 + 上传。 |
| 加载中 | 使用 Skeleton；不要整页只写“加载中…”。 |
| 网络断开 | 提示“网络好像断了一下”，同时说明草稿已经本地保存。 |
| 发送失败 | 消息保留在对话里，显示“发送失败 · 重试”，不清空。 |
| 表单刷新 | 创建 TA、故事、反馈等输入自动保存草稿并恢复。 |
| 生成任务中 | 显示任务状态；允许离开页面，完成后可从记录回来。 |

> 原则 错误提示必须回答三个问题：发生了什么？我的内容有没有丢？我现在可以做什么？

# 隐私、可信边界与删除

这是产品体验的一部分，不只是协议页。

| 场景 | 体验规则 |
| --- | --- |
| 上传照片时 | 就地说明“照片仅用于你选择的功能，可随时删除”。 |
| 上传声音时 | 明确 AI 模拟、授权范围、谁可访问；避免“复活/真人还原”等误导。 |
| 聊天回应 | 重要事实优先来自已确认记忆；未知时承认不知道。 |
| 家人贡献 | 展示来源；必要时由管理者确认，避免不同人的记忆互相覆盖。 |
| 删除 TA | 二次确认，明确会删除聊天、记忆、照片、声音等；提供导出/冷静期可作为后续版本。 |
| 主动消息 | 可关闭、可调频率、可设置静默时间，不制造“逝者真实来信”错觉。 |

> 删除确认文案 “删除关于 TA 的所有记录？”是高风险动作；按钮明确写“永久删除”，次按钮“保留”。不要用模糊的“确认 / 取消”。

# MVP 开发优先级与验收

先把状态连续性做对，再加高级 AI 能力。

| 优先级 | 范围 |
| --- | --- |
| P0 · 必须上线 | 匿名账号、首页两种状态、创建 TA 3 步、聊天、记忆确认、记忆中心、手机号绑定、找回、基础照片、草稿恢复、隐私删除。 |
| P1 · 第二阶段 | 声音保存/试听、家庭共建、重要日子、主动消息、订单/支付、微信环境引导、添加桌面。 |
| P2 · 验证后 | 照片动态化、完整声音模拟、视频、多人物家庭空间、公开社区、复杂订阅。 |

## 上线前必须走完的测试路径

- 第一次打开：不注册 → 创建 TA → 开始聊天。
- 聊天里讲一个故事 → 系统识别候选记忆 → 用户确认 → 记忆中心可见。
- 刷新聊天页、关闭浏览器再回来：身份、TA、草稿、历史均正确恢复。
- 未绑定用户产生多条数据后：绑定手机号 → 换浏览器/设备 → 恢复完整家庭空间。
- 微信打开：出现正确引导；关闭后不反复骚扰。
- 没有照片/声音/记忆/订单时：所有空状态都有明确下一步。
- 网络中断、发送失败、支付失败：输入不丢、状态可重试。
- 邀请家人：对方无需先注册即可贡献第一条内容；来源正确记录。
- AI 遇到未知共同经历：不编造，转为邀请用户补充。
- 删除 TA：清楚说明范围，并且不会误删其他家庭空间或账户数据。

> 完成标准 用户第一次使用不需要看教程；开发人员不需要猜页面逻辑；任何关键状态刷新后都能恢复；所有技术概念在前台都翻译成普通人能理解的话。
